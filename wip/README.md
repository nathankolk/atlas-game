A snapshot of the working material for the redesign on this branch: the globe engine and its tests, the
learning-history module and its tests, capitals data, the chosen design mockup's source, the integration
plan, the test harness and smoke suite, the code audits they were built from, and the pipeline scripts.

It is kept here only so an interrupted session cannot lose it. Files may be mid-edit. Nothing in this
folder is served (`public/` is the site), and the folder is removed before the branch is finished; the
parts that ship are pasted into `public/index.html` or moved to `public/vendor/` and `tools/`.
